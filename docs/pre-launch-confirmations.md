# 公開前の先方確認事項

初回公開前のチェックで見つかった、**サイト制作側では判断できない項目**をまとめたものです。
文言そのものは実装済みなので、回答が来た時点で該当ファイルを直せば反映されます。

判断が必要な理由ごとに分けています。

- **A. 運用実態の確認が必要** — 実際にどう運用するかが決まらないと文面を確定できない
- **B. 表現の判断が必要** — どちらでも動くが、ブランドとしてどう書くかを決める必要がある
- **C. Shopify 側の登録作業が必要** — サイト側では直せない

---

## A-1. お客様都合による返品で「到着後8日目」の扱い

**対象**: ショッピングガイド「5.返品・交換・キャンセルについて」／特定商取引法に基づく表記「返品・交換・キャンセルについて」／利用規約 第7条

現在、3つの文書すべてで次のように記載しています（数値は3文書で一致）。

| 区分 | 期限 |
|---|---|
| 初期不良・誤配送 | 商品到着後 **8日以内**にご連絡 |
| お客様都合 | 商品到着後 **7日以内** |
| 返品・交換をお受けできない場合 | 商品到着後 **9日以上**経過した場合 |

お客様都合の期限は7日以内ですが、受付できない条件は「9日以上経過」と書いてあるため、
**到着後8日目にお客様都合の返品を申し出た場合の扱いが、どちらの記述からも読み取れません**。
「7日を超えているので不可」が意図だと思われますが、お客様からは「8日目は不可と書いていない」と
読めてしまいます。

**確認したいこと**

- お客様都合の返品期限は7日以内で正しいか
- 初期不良の8日以内と、お客様都合の7日以内で日数を分けている意図はあるか（揃えるべきか）

**決まり次第の対応**: 「お受けできない場合」の条件を、お客様都合は「8日以上経過」と区分ごとに
書き分けるか、期限そのものを揃えます。3文書を同時に直します。

## A-2. 代金引換・後払いを取り扱うか

**対象**: 特定商取引法に基づく表記「商品代金以外に必要な料金」

特商法の表記では、商品代金以外に必要な料金として次を挙げています。

> - 送料：全国一律700円（税込価格5,000円以上で送料無料）
> - 各種決済手数料（**代引き手数料、後払い手数料**など）

一方、同じ文書の「支払方法」欄と、ショッピングガイドの「3.お支払いについて」は
どちらも次の4種類のみです。

> クレジットカード決済、Google Pay、Apple Pay、銀行振込

**代金引換と後払いは支払方法として提供していないのに、手数料だけが記載されています。**
さらにショッピングガイドの同じ欄は「各種決済手数料（**振込手数料**など）」となっており、
特商法の表記と食い違っています。

**確認したいこと**

- 代金引換・後払いを取り扱う予定はあるか
- 取り扱わない場合、手数料の記載は「振込手数料」のみに統一してよいか

**決まり次第の対応**: 取り扱わないなら特商法側を振込手数料に統一します。取り扱うなら、
支払方法欄・ショッピングガイドの両方に追記し、手数料の金額も明記します（特商法では金額の
明示が求められます）。

## A-3. Shop Pay を支払方法として案内するか（対応済み）

**回答**: Shop Pay は提供しない。ショッピングガイドから説明の項目を削除した。支払方法の一覧
（クレジットカード決済、Google Pay、Apple Pay、銀行振込）は元から Shop Pay を含まないため、
特商法の表記も変更なし。

**対象**: ショッピングガイド「3.お支払いについて」

支払方法の一覧は「クレジットカード決済、Google Pay、Apple Pay、銀行振込」の4種類ですが、
その下に **Shop Pay の説明が独立した項目として置かれています**（ログインページ・アカウント
削除ページへのリンクを含む説明）。

一覧に入っていないものの説明だけがある状態なので、お客様から見ると
「Shop Pay は使えるのか」が分かりません。

**確認したいこと**

- Shop Pay を支払方法として提供するか（Shopify の設定側で有効になっているか）
- 提供するなら、支払方法の一覧と特商法の表記にも Shop Pay を追記してよいか

**決まり次第の対応**: 提供するなら一覧と特商法へ追記します。提供しないなら説明の項目を
削除します。

## A-4. 領収書の発行方法

**対象**: ショッピングガイド「6.領収書、納品書について」

見出しは「領収書、納品書について」ですが、**本文は納品書の説明だけです**。

> 納品書は、お届けする製品に同梱し発送いたします。

**領収書について何も書かれていません。**

**確認したいこと**

- 領収書は発行するか
- 発行する場合の方法（注文完了メールを領収書として扱う／申し出があれば PDF を発行／同梱など）
- 宛名や但し書きの指定を受け付けるか

**決まり次第の対応**: 発行方法を本文に追記します。発行しない場合は見出しを「納品書について」に
変更し、代わりになるもの（注文確認メールなど）を案内します。

## B-1. 送料欄の見出しと中身のずれ

**対象**: ショッピングガイド「4.送料・配送について」

「■送料について」という見出しの下に、送料と決済手数料が並んでいます。

> ■送料について
> - 送料：全国一律700円（税込価格5,000円以上で送料無料）
> - 各種決済手数料（振込手数料など）

**決済手数料は送料ではない**ため、見出しと中身が合っていません。
特商法側は「商品代金以外に必要な料金」という見出しなので、こちらは両方を含んで問題ありません。

**提案**: 見出しを「■送料・手数料について」に変更する。または送料と手数料を別項目に分ける。

これは表現の問題だけなので、**指示があれば単独で修正できます**（A-2 の回答待ちにする必要は
ありません）。

## B-2. トップページ MOYA500 と MOYA420 のキャッチコピーが同一

**対象**: トップページ Main Products セクション

4商品のうち、MOYA500 と MOYA420 が**同じキャッチコピー**を使っています。

| 商品 | キャッチコピー |
|---|---|
| MOYA500 | THE GRAND DOME SHELTER. |
| MOYA420 | THE GRAND DOME SHELTER. |
| NOKUTA | PROTECTION UNDER THE SKY. |
| ZIG STAKE | BUILT TO HOLD. |

並んで表示されるため、2つの違いが伝わりません。MOYA420 は「MOYA500 をよりコンパクトな
サイズに凝縮した」製品なので、サイズ感の違いを出す余地があります。

**確認したいこと**: MOYA420 に別のコピーを用意するか、意図的に同じにしているか。

**決まり次第の対応**: サイト側のデータ（`data/home.ts`）なので、文言が決まればすぐ反映できます。

## C-1. MOYA420 と MOYA500 のオプション品で商品説明文が完全一致

**対象**: Shopify の商品説明文（4組8商品）

次の4組は、**説明文が1文字も違わず完全に一致**しています。

| オプション | 商品 | 説明文の文字数 |
|---|---|---|
| グランドシート | `moya420_groundsheet` / `moya500_groundsheet` | 約300字（完全一致） |
| インナーテント | `moya420_innertent` / `moya500_innertent` | 約170字（完全一致） |
| メッシュインナー | `moya420_innertent-mesh` / `moya500_innertent-mesh` | 約210字（完全一致） |
| ルーフシート | `moya420_roofsheet` / `moya500_roofsheet` | 約160字（完全一致） |

商品説明文はページ本文と meta description の両方に使われるため、
**Google から「実質的に同じページ」と判断され、片方だけがインデックスされる可能性があります**
（重複コンテンツ）。対応サイズが違う別商品なので、両方を検索結果に出したい場合は書き分けが必要です。

**確認したいこと**: 対応サイズ（420 / 500）に触れる形で書き分けていただけるか。

**決まり次第の対応**: Shopify 側の登録内容なので、**サイト側では修正できません**。
書き換えていただければ自動で反映されます。1〜2文の追記でも効果があります。

## C-2. MOYA500 TPUウインドウ の商品名と説明文で表記が違う

**対象**: Shopify の商品名と商品説明文（`moya500_tpu`）

同じページの中で「ウインドウ」と「ウィンドウ」が混在しています。

| 箇所 | 表記 |
|---|---|
| 商品名（ページ見出し・ブラウザタブ・一覧） | MOYA500 TPU**ウイン**ドウ |
| 商品説明文（本文・meta description） | 専用ハイブリッドTPU**ウィン**ドウ |

商品名が「ウインドウ」なので、ページ見出しと本文で表記が食い違って見えます。

**確認したいこと**: どちらに統一するか（一般的な表記は「ウィンドウ」です）。

**決まり次第の対応**: Shopify 側の登録内容なので、**サイト側では修正できません**。
商品名を直す場合は URL（handle）は変わらないため、リンク切れは起きません。

## C-3. 画像の代替テキスト（altText）でカラー名の大文字表記が混在

**対象**: Shopify の商品画像 altText

同じ商品の中で、カラー名が大文字と先頭大文字で混在しています。

| 登録状態 | 例 |
|---|---|
| altText 登録済みの画像 | MOYA500 ルーフシート **CLASSIC YELLOW** |
| altText 未登録の画像（サイト側が商品名＋カラー名で自動生成） | MOYA500 **Classic Yellow** |

**優先度は低いです。** 代替テキストは画面に表示されないため、見た目には影響しません。
画像検索とスクリーンリーダーでの読み上げにのみ関わります。

**確認したいこと**: altText を登録する際、カラー名の表記を揃えていただけるか。
登録がなくてもサイト側が「商品名＋カラー名」を自動で入れるため、**未登録でも問題ありません**。

## C-4. 関連商品リンクのラベルに空白が足りない

**対象**: Shopify の商品特徴（`product_feature`）のリンクラベル

MOYA500 と MOYA420 の商品ページに、関連商品への「詳細ページ」リンクが並んでいます。
その中の1つだけ、商品名と数字が繋がっています。

| 現在のラベル | 飛び先 |
|---|---|
| インナーテント 詳細ページ | 該当商品 |
| メッシュインナーテント 詳細ページ | 該当商品 |
| **ZIG STAKE20 詳細ページ** | `/products/zig-stake` |
| 三角自在金具 詳細ページ | 該当商品 |
| ガイロープ 詳細ページ | 該当商品 |

**リンクの飛び先は正しいです。** 表示される文字が「ZIG STAKE20」となっている点だけの問題です。
ZIG STAKE には 20cm と 30cm があるので、意図が2通り考えられます。

**確認したいこと**: 「ZIG STAKE 詳細ページ」（商品全体へ）と
「ZIG STAKE 20cm 詳細ページ」（サイズを明示）のどちらが意図か。

**決まり次第の対応**: Shopify 側の登録内容なので、**サイト側では修正できません**。
